# 当前工程状态

## 可运行系统

一个自建控制服务、SQLite 操作账本、私有镜像目录、Python HTTP SDK 和 CLI。当前现场为两块 ESP32-S3，运行构建 4.0.0、协议 edbg.agent/v1；节点主动建立 HTTPS 连接，不要求公网入站访问节点。

| 功能 | 当前实现 |
| --- | --- |
| 节点事实 | 芯片家族、协议、构建、健康、启动、完整运行镜像 SHA-256/长度与版本化驱动能力 |
| 配置 | 自身/外部目标、接口连接、固定修订与无副作用计划 |
| 操作 | 持久接受、同键重试、单次发布、事件、取消边界、未知及后到结果核对 |
| UART | 固定接线的会话、有限写入、显式续租、独立消费者 RX 日志 |
| I²C | 固定 GPIO9/10、10 kHz、64 字节/方向、单写/单读/写后读 |
| 节点更新 | 镜像登记/撤回、结构/校验和/摘要检查、维护互斥、新健康启动的 Flash 身份确认 |
| 采集原型 | 有限单通道波形、信号生成与解码，尚未统一操作与产物模型 |

执行依据是已知协议与提供者，不是某个构建版本字符串。严格 OTA 只接受 image_identity；直接任务入口不能创建 OTA，也没有弱确认回退。节点 Flash 测量不是硬件根远程证明，发布者签名和安全启动尚未实现。

## 主要待完成事项

1. 消除调试驱动中的固定 MAC、A/B 角色和引脚；连接显式描述资源，节点最终校验。
2. I²C/GPIO 原生有限执行器；I²C 不再启用 UART，不同总线不再受台架全局锁限制。
3. 可配置 UART、节点确认的租约修订、最终接收检查点与完整排空。
4. 原始逻辑采集、触发、产物导出和派生解码；监听与注入分开授权。
5. 构建/固件/符号/转储关联、真实外部烧录提供者、有限多节点实验和独立人/AI 身份。

详细完成条件见 [研发顺序](architecture/08-next-implementation-batch.md)。整个系统目标尚未完成，不能由部分通过的测试代替完整平台验收。

## 当前验证依据

机器验证覆盖操作幂等、资源互斥、事务故障、独立进程、超时、迟到确认、租约和游标。运行信息新增未知协议/家族、健康、构建一致性、能力与冻结镜像变化的拒绝检查；OTA 新增相同版本但错误摘要、错误长度和缺失测量的拒绝检查。

- 功能/客户端/集成测试：113 项，入口为 tests/。
- 服务与驱动协调回归：44 项，入口为 fleet/tests/。
- 请求契约自检：6 项；运行信息和响应 Schema 单独校验。
- 实板：两节点 Flash 摘要、长度与构建文件一致；B 板严格 OTA 取得新启动和健康匹配镜像；原键返回原操作。
- 实板：A 串口发送的字节在 B 的受管 RX 流中完整收到，两端随后确认关闭。

原始结果覆盖写入本机 artifacts/runtime-live.json、strict-update-result.json、functional-tests.log、service-tests.log 和 package-check.json。它们供复核当前状态，不作为逐次开发日志；运行系统的操作证据与审计记录仍保留。

模拟成功不代表真实外设成功；I²C 新接口仍缺外部应答器成功读写验证。其他芯片、外部烧录、深度断点调试、批量发布、硬件签名链和公网部署尚未验收。没有因本轮后端修改重复做浏览器 UI 测试。
