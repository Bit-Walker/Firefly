# 0004 UART 接收日志与独立游标

状态：已实施 v0，2026-10-27。

## 决定

每个受管 UART 会话建立一条包含已启用 RX 通道的持久日志。读者仅持有外部游标，不竞争消费设备缓冲；只有服务的已提交接收检查点参与设备 ACK。

服务日志位置、节点帧序号和两个时间来源分别保存。序号缺口、源丢块计数、服务裁剪和不可恢复历史分别记录，不能相加或混称为字节损失。

采用有界 HTTP 分页和 CLI NDJSON 跟随。裁剪只删除日志前缀并保留游标下界；过期游标返回明确错误和恢复位置，工具不自动跳过。

## 兼容代价

旧节点跨两个 UART 共用帧序号，因此缺失可能无法归属端口。关闭时缺少最终排空确认，tail_complete 固定为 false；日志末尾和物理采集完整性分别表达。

保留旧 debug_rx 接口以兼容现有网页。新增全局限额仅约束新流的记录及原始载荷，不宣称解决全部数据库容量与历史清理问题。

未来代理协议可增加逐通道完整性、最终水位、持久采集及新的传输方式，继续复用流身份和消费者游标语义。
