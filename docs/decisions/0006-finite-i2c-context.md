# 0006 有限 I²C 与独占清理

状态：已实施的兼容选择，2026-10-27。

## 决定

有限 I²C 请求自行取得临时调试上下文，不借用或关闭用户 UART 会话。当前兼容驱动关联 UART 的事实进入资源计划与结果，暂不宣称外设完全隔离。

总线命令采用单次发布；读取也可能有副作用，不自动重试。保存主机报告与整体清理状态，事务已完成不自动代表所有资源已释放。

新旧入口共用适配器全局互斥。释放未确认时保留占用，整体可结束为未知；后到证明修订原操作，不创建新执行。节点无精确中途进度时不虚构部分字节数量。

## 影响

清理阶段会增加延迟，未知释放可能阻挡后续事务，但避免通过另一个节点或旧接口重复驱动同一总线。当前全局范围只适用于已知固定台架，未来独立物理总线的并行需要新的已验证适配器和资源模型。

成功主机报告只证明其完成语义，外设业务验证独立处理。实测与模拟证据分别记录，不通过模拟应答掩盖未连接真实外设。
