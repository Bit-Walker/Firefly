# 0005 控制器显式续租与修订检查

状态：已实施的兼容选择，2026-10-27。

## 决定

受管 UART 用显式 uart.session.renew 操作续租，复用持久账本与稳定主体。调用者提供预期租约修订，采用事务内比较更新；相同幂等键返回原期限，不重复延长。

期限设置为接受时刻加请求时长，最多向后 300 秒，不在原期限上累加，也不允许缩短。读取、跟随、普通写入和登录不续租。

续租证明级别为 server_policy。租约修订、操作修订和连接修订分别表示控制器状态、账本观察和配置绑定；租约修订不充当旧固件已经确认的控制代次。

已经活动的受管会话失去匹配快照后停止旧控制，不自动重开；不确定释放仍等待节点证明。已结束、过期或旧启动的上下文不能被续租恢复。

## 影响

滚动续租可延长长期开发会话，但每次都需要明确意图与当前修订。未知写入不因续租变成可安全重试，关闭始终是独立清理动作。

后续代理协议应增加节点端修订确认与失效校验，不能因为本批已有 revision 字段就宣称端到端 fencing 完成。
