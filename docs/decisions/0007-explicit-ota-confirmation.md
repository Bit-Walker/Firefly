# 节点更新与运行镜像

节点更新使用健康新启动与实际运行 Flash 的完整文件 SHA-256、长度、项目和目标版本共同确认。下载成功或版本字符串相同都不足以证明正在运行指定镜像。确认级别只有 image_identity，不提供降级路径。

节点的 edbg.agent/v1 运行信息与构建版本分离，驱动能力按版本声明。服务冻结接受时的协议、启动、镜像和能力，派发前核对变化；未知节点驱动不被版本字符串猜测为可用。

镜像存储检查规范 ESP 应用分段、校验和、附加摘要和精确长度；签名或硬件证明需要单独实现，不由普通摘要代替。

更新复用唯一持久操作和维护占用，不创建 UART 会话。单次发布、未知时保留占用、后到证据核对和取消边界是执行语义，不是历史接口兼容要求。

研发直接更新当前方案与接口，不为未发布的旧确认模式保留分支。
