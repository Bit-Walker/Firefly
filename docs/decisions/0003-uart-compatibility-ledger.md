# 0003 UART 兼容操作账本

状态：已实施的兼容选择，2026-10-27。不冻结未来通用动作协议。

## 决定

第一条执行闭环使用现有 3.5.0 UART 驱动与设备轮询，不同时升级固件。通过编号迁移追加持久操作、事件和连接会话绑定；新旧入口共用既有互斥和发送记录。

UART 写入在同一轮询事务中记录发布，只向设备发布一次，不因未确认或服务重启自动重复发送。相同持久幂等键重试返回原操作；迟到证据修订原结果并保留事件。

认证继续使用单管理员，稳定主体 local-admin 与登录 cookie 分离。旧 cookie 会话不自动转换成受管会话，也不能绕过其连接修订快照。

## 理由与代价

优先验证业务意图、数据库提交与物理副作用之间的边界。单次发布会牺牲一部分投递成功率：响应丢失时可能根本没有发送，但仍需报告未知，不能靠重发来掩盖不确定性。

旧代理没有新的逐操作执行预算字段或掉电持久去重。响应 compatibility 显式标明等级 legacy_uart_once 和预算限制，不将兼容执行包装为未来协议的完整实现。

会话关闭只在节点报告结束或新启动核对后确认释放。终局未知结果与资源状态分开；收到驱动确认也不代表目标业务成功。

后续数据流、代理协议和资源调度继续在这些持久身份上演进，避免再产生另一套会话或操作账本。
