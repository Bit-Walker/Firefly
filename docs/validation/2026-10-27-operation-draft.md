# 操作请求草案离线验证

日期：2026-10-27。对象：`contracts/drafts/operation-v0/`。

本轮交付三场景推演、操作契约候选规则、下一批实施边界，以及六种动作的请求 Schema 与占位样例。未修改服务运行逻辑、固件、数据库或现有 CLI 命令。

执行 `python contracts/tools/check_drafts.py`，6 组检查通过：

1. Schema 自身合法，六种动作样例符合结构约束。
2. 未知字段、版本与动作拒绝。
3. 缺失连接修订或执行期限拒绝。
4. 不同动作的参数不能混用。
5. 非法字节、地址与混合 I²C 消息拒绝。
6. 重复键、非有限数值、浮点数与布尔修订号拒绝。

证据：本机 `artifacts/operation-draft-checks.log`。文档相对链接及公开分发包中的草案文件另做路径检查。

这是离线的协议结构验证，不验证调度、幂等账本、实际执行、真实电气连接或节点行为。该轮尚未接入服务；后续版本仅增加了 [预检查入口](../reference/workspace-v0.md)，尚未实现统一动作执行。
